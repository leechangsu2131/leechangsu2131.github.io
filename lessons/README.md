# lessons/ — 수업 진행판 수업 데이터

`lesson-board.html`(수업 진행판)이 읽는 수업 한 개 = 이 폴더의 파일 하나(`castle.js` 등) 또는 휴대폰에서 붙여 넣어 가져온 JSON 하나입니다. 진행판 화면 코드에는 특정 수업의 글이 없습니다. 단계·시간·할 말·카드는 전부 아래 형식의 데이터에서 나옵니다.

## 새 수업 만드는 두 가지 길

**① 휴대폰/PC에서 바로 (파일 수정 없음, 추천)**
1. `lesson-board.html` 을 열고 「＋ 새 수업 가져오기」를 누른다.
2. 「Claude에게 줄 요청문 복사」를 눌러 Claude 대화창에 붙여 넣고, 그 아래에 수업 계획(지도안)을 이어 붙인다.
3. Claude가 돌려준 JSON을 칸에 붙여 넣고 「가져오기」. 틀린 곳이 있으면 어느 단계·어느 칸인지 알려 준다.
4. 가져온 수업은 **이 기기(브라우저)에만** 저장된다(`localStorage`). 다른 기기에서 쓰려면 목록의 「JSON 복사」로 옮긴다.

**② 사이트에 기본 수업으로 올리기**
1. `lessons/새수업.js` 를 만든다. 파일 안에서 `registerLesson({ ... })` 를 한 번 부른다(`castle.js` 참고).
2. `lesson-board.html` 의 `<script src="lessons/castle.js"></script>` 아래에 같은 모양으로 한 줄 더한다.
3. `AGENTS.MD` 16-4 절의 수업 목록에 한 줄 적는다.

## 형식

```json
{
  "id": "music-rhythm",
  "title": "내가 만드는 리듬",
  "subtitle": "3학년 음악 · 40분",
  "fileLabel": "리듬수업",
  "logTitle": "리듬 수업 기록",
  "record": false,
  "steps": [
    {
      "name": "도입", "tag": "Warm-up", "min": 5, "flag": "",
      "beats": [
        { "t": "0:00 · 2분", "do": "교사가 할 일", "say": ["교사가 말할 문장", "두 번째 문장"] }
      ],
      "tip": "참고 글(선택)",
      "picker": 0
    }
  ],
  "cards": {
    "button": "리듬 카드",
    "title": "리듬 카드",
    "pick": "카드를 고르세요",
    "fields": ["박자", "말"],
    "big": 1,
    "groups": [ { "g": "기본", "items": [ ["따다", "4/4", "따 따 따"] ] } ]
  }
}
```

| 칸 | 뜻 | 필수 |
|---|---|---|
| `title` | 수업 이름(60자) | ✔ |
| `id` | 영문 소문자·숫자·`-`·`_` (가져오기에서 비우면 자동) | 내장 수업은 ✔ |
| `subtitle` | 시작 전 안내 한 줄 | |
| `fileLabel` / `logTitle` | 저장 파일 이름 앞부분 / 기록 문서 제목 | |
| `record` | `true` 면 "이 수업을 녹음해요" 칸이 처음부터 켜져 있음. 기본 `true` | |
| `steps` | 단계 목록(1~30개) | ✔ |
| `steps[].name` | 단계 이름 | ✔ |
| `steps[].min` | 배정 분(0 초과 240 이하, 소수 가능). 시계·진행 띠·늦음 표시가 이 값으로 계산됨 | ✔ |
| `steps[].flag` | `"keep"` 줄이지 말 것 / `"cut"` 시간이 밀리면 줄여도 됨(늦으면 줄일 단계로 안내) / `""` 없음 | |
| `steps[].tag` | 단계 이름 아래 작은 글씨(활동 이름 등) | |
| `steps[].beats[]` | 활동 목록. `t` 시각·시간 표시, `do` 교사 할 일, `say` 교사가 말할 문장 목록(말할 게 없으면 `[]`) | |
| `steps[].tip` | 노란 참고 상자 | |
| `steps[].picker` | 이 번호(0부터)의 활동 아래에 "카드 고르기"를 붙임. `cards` 가 있어야 함 | |
| `cards` | 카드 서랍(선택). `fields` 는 칸 이름 1~4개, 카드 하나는 `["이름", 칸1, 칸2, …]`, `big` 은 크게 보일 칸 번호(0부터) | |

- 글 안에서 `**굵게**` 와 `\n`(줄바꿈)만 쓸 수 있다. HTML 태그는 글자 그대로 보인다(실행되지 않음).
- 한 글 칸은 3000자, 단계 30개·활동 30개·카드 60개까지.
- 학생 이름·번호·사진은 넣지 않는다(수업 계획을 AI에게 줄 때도 마찬가지).

## 저장 위치와 호환

- 단계 위치·기록: `localStorage` `lesson-<id>-step` / `-log` / `-rec`. 성 수업만 예전 키(`castle-step`, `castle-log`)를 그대로 이어서 쓴다(`legacyPrefix`).
- 임시 녹음: IndexedDB `castle-rec`(성 수업 때 이름 그대로). 조각마다 `lesson` 이름표가 붙고, 이름표가 없는 예전 조각은 성 수업으로 본다.
- 가져온 수업 본문: `localStorage` `lesson-custom-<id>`, 마지막으로 연 수업: `lesson-last`.
