# 실시간 수업 모니터링

정적 홈페이지에서 Supabase를 통해 수업방을 열고, 학생 페이지의 화면 상태를 교사에게 보여 주는 기능입니다.

## Supabase 설정

1. Supabase Dashboard의 **SQL Editor**에서 `schema.sql` 전체를 한 번 실행합니다.
2. 이 기능은 기존 `student_games_admin`의 교사 비밀번호 해시(`id = 1`)를 사용합니다. AI 게임 검토실에서 쓰는 비밀번호가 그대로 적용됩니다.
3. Supabase 프로젝트가 바뀌었다면 `teacher.html`, `student.html`, `monitor.js`의 프로젝트 URL과 publishable key도 그 프로젝트 값으로 바꿉니다.

## 수업 진행

1. 교사는 [교사용 수업 화면](teacher.html)을 열고 **수업방 열기**를 누릅니다.
2. 생성된 입장 링크를 학생에게 보냅니다. 학생은 수업 코드, 번호, 이름을 입력하고 참여합니다.
3. 학생은 교육 페이지로 이동합니다. 지원되는 홈페이지 HTML에는 `classroom/monitor.js`가 연결되어 있어 페이지를 이동해도 참여 상태가 이어집니다.
4. 교사는 3초마다 갱신되는 학생별 화면 미리보기와 접속/탭 이탈 상태를 확인하고, 안내·주의집중·페이지 이동·내보내기를 사용할 수 있습니다.

## 화면 캡처 범위

- 캡처 대상은 학생이 현재 보고 있는 **이 홈페이지 탭의 브라우저 화면**입니다. OS 전체 화면, 다른 앱, 다른 탭, 카메라, 마이크는 캡처하지 않습니다.
- 학생에게 화면 모니터링이 동작 중임을 고정 표시하고, 화면 공유를 일시 중지하거나 수업에서 나갈 수 있게 합니다.
- 캡처는 매번 JPEG 축소본으로 전송하며 DB에는 가장 최근 화면만 보관합니다. 교사가 수업을 종료하면 화면 이미지를 지우고, 30일이 지난 수업방은 다음 방을 열 때 삭제합니다.
- 화면 렌더링은 `html2canvas`를 jsDelivr에서 불러옵니다. 네트워크 정책이 CDN을 막으면 접속 상태와 교사 명령은 계속 동작하지만 화면 미리보기는 나타나지 않을 수 있습니다.
- 교사의 명령은 학생 웹페이지 안에서만 작동합니다. 학생의 기기 전체를 잠그거나 다른 앱을 제어하지 않습니다.

## 데이터/권한

- 학생 화면은 공개 가능한 Supabase publishable key만 사용합니다. 테이블 직접 권한은 없고 모든 읽기/쓰기는 제한된 RPC 함수로 처리합니다.
- 교사용 RPC는 기존 `student_games_admin.code_hash`와 입력한 교사 비밀번호가 일치해야 작동합니다.
- 학생 접속 토큰은 브라우저에서 생성해 해시로 저장하고, 해당 학생의 heartbeat·화면·명령 조회에만 사용합니다.
- 학생 번호와 이름은 입력값입니다. 이 기능은 학급 명단 인증 기능은 아니므로 교사가 참가자 목록을 확인해야 합니다.
